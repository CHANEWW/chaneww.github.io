💧 앙금 생성 반응 화학
1. 앙금이란?
두 수용액을 섞었을 때 물에 녹지 않는 고체가 만들어져 바닥에 가라앉는 것을 앙금이라고 해요. 앙금은 대개 흰색이나 노란색이고, 잘게 부서진 결정 모양이에요.
2. 반응하는 이온과 구경꾼 이온
수용액 속 이온은 모두 따로 떨어져 움직여요. 그중 서로 만나 앙금을 만드는 이온(알짜 이온)만 반응하고, 나머지 이온(구경꾼 이온)은 반응하지 않고 그대로 물속을 떠다녀요.
예) 질산 은 + 염화 나트륨 → 반응하는 이온은 Ag⁺, Cl⁻ / 구경꾼 이온은 Na⁺, NO₃⁻
3. 화학 반응식 → 알짜 이온 반응식
AgNO₃ + NaCl → AgCl↓ + NaNO₃
양쪽에 똑같이 들어 있는 Na⁺, NO₃⁻를 지우면 Ag⁺ + Cl⁻ → AgCl↓ 가 남아요. 이를 알짜 이온 반응식이라고 해요. '↓'는 앙금이 생긴다는 표시예요.
4. 대표적인 앙금
앙금알짜 이온 반응식색
AgClAg⁺ + Cl⁻ → AgCl↓흰색
AgIAg⁺ + I⁻ → AgI↓노란색
PbI₂Pb²⁺ + 2I⁻ → PbI₂↓노란색
CaCO₃Ca²⁺ + CO₃²⁻ → CaCO₃↓흰색
BaSO₄Ba²⁺ + SO₄²⁻ → BaSO₄↓흰색
