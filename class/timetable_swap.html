👥 상대 선생님 시간표

🔀 교체 추천

이번 주·다음 주, 요일, 교시(1교시 · 2~3교시 · 오전 · 오후 · 하루 종일)를 적으면 그 교시를 자동으로 골라 추천합니다. ‘금요일 연가’, ‘다음 주 월요일 출장’, ‘오후 반차’처럼 적어도 알아듣습니다.
⇅ 순위 목록 — 위아래로 밀면 4~7순위까지 볼 수 있어요

⚙️ Worker 연결

컴시간 알리미 실시간 시간표를 받아오는 Cloudflare Worker 주소입니다. 기본 Worker가 이미 연결되어 있어 보통은 그대로 두면 됩니다.

안내
기본 Worker가 자동 연결되어 있어, 업무 화면에서 인증만 마치면 실시간 시간표를 받아옵니다(10분 캐시 · 학교별 캐시 분리).
문산중/대곡중 탭을 바꾸면 해당 학교 코드(61208 / 94305)로 자동 조회합니다.
Worker에 연결하지 못하면 시간표 대신 연결 실패 안내가 표시됩니다.
