모둠이 측정한 실험값을 한 화면에 모아 산점도와 최소제곱 추세선, 결정계수 R²를 바로 보여 줍니다. 4자리 PIN 방을 만들고 모둠별 값을 입력하세요.

🆕 새 방 만들기

4자리 PIN이 자동으로 만들어집니다. 칠판 화면에 이 보드를 띄워 두고 모둠 대표가 값을 입력합니다.
