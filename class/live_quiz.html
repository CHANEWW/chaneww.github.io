⚙️ Cloudflare Worker 설정

실시간 모드에서 쓰는 Worker 주소입니다. 배포한 주소를 붙여 넣으세요.

❓ 이렇게 씁니다

  1. 세트 고르기 · 오른쪽에서 문항을 고치거나 새로 만듭니다.
  2. 방 열기 · 6자리 코드와 QR이 나옵니다. 칠판에 띄우세요.
  3. 학생 입장 · 학생이 QR을 찍거나 주소에 코드를 넣습니다. PIN은 필요 없습니다.
  4. 진행 · 시작 → 정답 공개 → 다음. 점수와 순위가 자동으로 쌓입니다.
  5. 마무리 · 시상대로 1·2·3위를 보여 주고 방을 닫습니다.

같은 브라우저의 탭끼리는 브라우저 연습으로 바로 시험해 볼 수 있습니다. 다른 기기(학생 폰)가 붙으려면 Cloudflare Worker를 배포하고 실시간 모드로 여세요.
