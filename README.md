[![Three.js](https://img.shields.io/badge/Tech-Three.js%20r128-black?style=flat-square)](https://threejs.org/)

**Science Virtual LAB**은 중·고등학교 과학 교육과정을 위해 현직 과학교사가 직접 제작한 **설치·가입·광고 없는 무료 웹 3D 과학 가상실험실**입니다.

교실의 전자칠판, 1인 1스마트기기(크롬북, 아이패드, 갤럭시탭), 스마트폰, PC 등 기기에 구애받지 않고 웹 브라우저에서 터치와 마우스로 직관적인 3D 가상실험을 조작할 수 있습니다.

👉 **실험실 바로가기**: **[https://chaneww.github.io](https://chaneww.github.io)**

---

## 🌟 주요 특징

- **100% 무료 / No Ads / No Sign-up**: 별도의 계정 생성이나 로그인 없이 URL 링크만으로 즉시 실행됩니다.
- **반응형 3D 터치 최적화**: 스마트폰부터 태블릿, 대형 전자칠판까지 화면비에 맞춰 자동 프레이밍 및 터치 제스처를 지원합니다.
- **5개 국어 글로벌 지원**: 한국어, English, 日本語, 简体中文, Español 완벽 지원.
- **2D 메인 허브 & 3D 공간 허브**: 카드 그리드 탐색(2D)과 1F~6F를 오르내리는 회전식 3D 원형 쇼케이스(3D)를 함께 제공합니다. 3D 허브에는 126종 전체가 층별로 빠짐없이 수록되어 있습니다. (2026-11 통합 기준)
- **6개 탭 + 세부 영역 칩**: 물리학 · 화학 · 생명과학 · 지구과학 · 게임 · 교실도구 탭을 고르고, 교육과정 세부 영역 칩으로 다시 걸러 볼 수 있습니다.
- **실시간 통합 검색**: 탭과 세부 영역을 넘나들며 실험·도구 이름과 설명으로 바로 찾습니다.
- **수업 운영 지원**: 학급 배포용 QR 코드, 제안하기(피드백) 창, 교실도구(자리 배치·타이머·보고서·학습지), 게임 명예의 전당 TOP 10.
- **오프라인 앱 설치(PWA)**: `manifest.json` + 서비스 워커(`sw.js`, Network-First)로 홈 화면에 앱처럼 설치하고, 인터넷이 끊겨도 최근에 열었던 실험은 그대로 열립니다.
- **🛰️ 오늘 실제 날씨 연동**: 기압과 바람(해륙풍)·온난·한랭 전선·기단과 우리나라 계절 3개 실험에서 Open-Meteo 무료 API(키 불필요)로 서울·진주·부산·대구·광주·제주·강릉(또는 현재 위치)의 실제 기온·해면기압·풍속·풍향을 불러와 3D 시뮬레이션 값에 바로 반영합니다. 연결이 안 되면 안내 문구로 대체하고 기본 설정으로 실험합니다.

- **추와 용수철 3D**: 추의 무게에 따라 늘어나는 용수철의 길이를 재어 탄성계수 확인
- **단순 조화 진동 3D**: 단진동 운동의 특징과 역학적 에너지 변화 관찰
- **자유 낙하 운동 3D**: 진공 vs 공기 중 깃털과 쇠구슬 낙하 비교
- **역학적 에너지 보존 3D**: 롤러코스터 레일 위 위치에너지와 운동에너지 실시간 막대그래프
- **포물선 운동 3D**: 수평 투사 vs 자유낙하 동시 비교 및 속도 벡터($v_x, v_y, v$) 실시간 분해
- **2차원 충돌·추돌 실험 3D**: 질량·초속도·각도·마찰·반발계수를 바꾸며 2차원 평면에서 여러 공의 충돌과 추돌 관찰
- **마찰력과 힘의 평형 3D**: 여러 힘을 걸어 마찰력과 합력, 힘의 평형 상태를 3D 화살표와 수치로 확인
- **무게와 질량 3D**: 같은 물체를 지구와 달에서 용수철저울·양팔저울로 재어 무게는 장소에 따라 달라지고 질량은 같음을 확인
- **접촉 면적에 따른 압력 3D**: 벽돌을 세우거나 눕혀 접촉 면적을 바꾸며 압력과 눌린 깊이 비교
- **빗면 수레와 다중섬광 3D**: 빗면 각도와 처음 속력에 따른 가속도, 시간–속력·시간–이동거리 그래프 변화
- **롤러코스터 트랙 설계 3D**: 출발 높이·루프 반지름·두 번째 언덕을 직접 설계하고 루프 통과 여부를 에너지로 확인
- **우주 체육대회 중력 비교 3D**: 달(1/6g)·화성(0.38g)·지구(1g)·목성(2.53g)에서 같은 힘으로 공 던지기·자유투·높이뛰기를 해 보고 궤적과 기록 비교
- **바람 터널 3D**: 받음각·풍속·공기 밀도·무게중심을 바꾸며 평판·에어포일·종이비행기에 생기는 양력·항력과 압력 분포, 실속 확인

- **빛의 굴절과 전반사 3D**: 굴절각과 임계각, 전반사가 일어나는 조건을 3D 광선으로 확인

#### 물질의 특성과 반응 (11) — `labs/chemistry/reaction/`
- **앙금 생성 반응 3D**: 두 수용액의 이온 반응과 앙금 침전
- **용해도 곡선 3D**: 온도에 따른 용해도와 재결정 석출, 기체의 용해도
- **화학 반응식과 분자 결합 3D**: 물 합성($2\text{H}_2 + \text{O}_2 \rightarrow 2\text{H}_2\text{O}$)과 암모니아 합성($\text{N}_2 + 3\text{H}_2 \rightarrow 2\text{NH}_3$)의 충돌·재배열 및 원자 보존
- **산·염기 중화반응 3D**: 수소 이온과 수산화 이온의 반응, 지시약 색 변화와 중화열
- **중화 적정 3D**: 뷰렛 코크를 열어 수산화 나트륨 수용액을 떨어뜨리며 pH·지시약 색·이온 수 변화로 중화점 찾기
- **물의 전기분해 3D**: 전압·전해질을 바꾸며 (+)극 산소와 (−)극 수소가 2 : 1 부피비로 모이는 모습 관찰
- **불꽃 반응 색 실험 3D**: 시료를 불꽃에 넣어 나타나는 색으로 원소를 구별하고 미지 시료 퀴즈로 확인
- **크로마토그래피 색소 분리 3D**: 검정 사인펜 잉크를 거름종이에 찍어 물·에탄올로 전개하며 색소가 나뉘는 원리와 Rf 값 확인
- **질량 보존 법칙 3D**: 앙금 생성과 기체 발생 반응을 열린 비커와 닫힌 페트병에서 저울로 재어 반응 전후 질량 비교
- **일정 성분비 법칙 3D**: 구리와 마그네슘을 가열해 결합하는 산소의 질량비가 금속의 양과 관계없이 일정한지 확인
- **CSI 미지 물질 감별 3D**: 불꽃반응·밀도·용해도·pH·앙금 생성 다섯 검사를 시료마다 실행하고 관찰 기록으로 미지 시료 세 가지의 정체 추리

과학 실험 페이지는 `labs/{영역}/{세부 영역}/` 아래에 있고 공통 모듈을 `../../common/`으로, 교실 도구(`class/`)·게임(`game/`) 페이지는 각 폴더 바로 아래에서 `../labs/common/`으로 불러옵니다. 2026-11-17 개편으로 교실도구·게임이 루트 `class/`·`game/`으로 옮겨졌고, 2026-11-18 개편으로 `labs/test/`에 남아 있던 실험 13종이 각 세부 영역 폴더로 옮겨졌습니다. 옛 `labs/class/`·`labs/game/`·`labs/test/` 주소는 `404.html`이 새 주소로 안내합니다(쿼리·해시 유지).

폴더별 파일 수는 실제 파일 위치이고, 목록 위쪽의 세부 영역 개수는 2D 메인 탭 기준이며 두 수가 모두 일치합니다.
